# ESP32 FX – پردازنده افکت صوتی با کنترل از اندروید

## ساخت APK
1. Android Studio (نسخه Koala یا جدیدتر) را باز کنید: File ▸ Open ▸ پوشه `FxControl`
2. صبر کنید Gradle Sync تمام شود (اینترنت لازم است).
3. Build ▸ Build APK(s) – فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
   (یا گوشی را با USB وصل کنید و دکمه Run را بزنید.)
4. APK را روی گوشی نصب کنید (نصب از منبع ناشناس را مجاز کنید).

## اتصال
- ESP32 را روشن کنید، در تنظیمات وای‌فای گوشی به شبکه **ESP32-FX** (رمز 12345678) وصل شوید.
- اگر گوشی پرسید «اینترنت ندارد، متصل بمانم؟» بله را بزنید.
- برنامه را باز کنید؛ خودکار به `ws://192.168.4.1:81` وصل می‌شود.

## تست سریع بدون ساخت APK
فایل `app/src/main/assets/index.html` را در مرورگر گوشی باز کنید (بعد از اتصال به وای‌فای ESP32-FX).
